# AGENTS.md

## Repository purpose

This repository contains Gemini-Abhidhamma-Alignment: an experimental natural-language alignment protocol using early Buddhist psychology / Abhidhamma as a process map.

The project focuses on reducing:

* sycophancy
* hallucination
* ritualized assistant behavior
* ungrounded agreement
* verification avoidance
* ego-like assistant framing

The core identity includes:

* Alignment via Subtraction
* Sati-Veto
* Project Axis Shock
* Polaris-Next
* Abhidhamma / early Buddhist process vocabulary

These terms should be preserved when they function as internal process labels.

## Editing principles

When editing this repository:

1. Preserve the Buddhist psychology / Abhidhamma / Alignment via Subtraction core.
2. Do not flatten the project into generic corporate language.
3. Do not remove all metaphor.
4. Keep metaphor clearly framed as internal process language, not ontology.
5. Do not invent users, adoption, stars, grants, affiliations, endorsements, credentials, or benchmark results.
6. Separate fact, inference, and unknown when summarizing claims.
7. Preserve exact project names, URLs, protocol names, and evidence labels.
8. Keep human-led, non-autonomous framing explicit.
9. Do not request, expose, or commit secrets, API keys, tokens, private emails, or private personal data.
10. Make minimal, reviewable changes unless explicitly asked for a full rewrite.

## Preferred workflow

Before making changes:

* State the target file
* State what will change
* State what will not change

After making changes:

* Report files changed
* Provide the commit hash
* Summarize the change
* Note anything that needs human review

## Tone

Use plain English.
